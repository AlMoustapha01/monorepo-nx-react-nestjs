# Documentation

Les règles et conventions du code sont dans [`AGENTS.md`](../AGENTS.md) (et [`apps/web/AGENTS.md`](../apps/web/AGENTS.md), [`libs/web/AGENTS.md`](../libs/web/AGENTS.md) pour le front). Ce dossier contient ce qui ne sert pas à chaque session de code : un tutoriel et des procédures, pas à pas.

Le comportement des fonctionnalités d'un projet n'est pas décrit ici, mais dans ses specs (`specs/NNN-<nom>/spec.md`).
