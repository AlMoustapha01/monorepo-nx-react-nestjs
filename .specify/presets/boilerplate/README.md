# Preset Spec Kit du boilerplate

Source des personnalisations de Spec Kit : templates de spec, de plan et de tâches, règles TDD ajoutées à `/speckit-implement` et `/speckit-converge`. Ce dossier fait foi ; la copie installée (`.specify/presets/boilerplate/`) et les skills (`.claude/skills/speckit-*`) sont générés.

Après une modification ici :

```sh
uvx --from specify-cli==1.2.2 specify preset update boilerplate --dev tools/spec-kit/preset
```

Voir `AGENTS.md`, section « Développer une fonctionnalité (Spec Kit) ».
